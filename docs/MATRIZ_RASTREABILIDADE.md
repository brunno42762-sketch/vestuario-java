# Matriz de rastreabilidade

Requisito original → problema ou lacuna → requisito revisado ou novo → justificativa →
implementação → teste ou evidência.

Os códigos RL (requisitos legados), P (problemas), RF e RNF são os da Entrega 1 (seções 2.5, 3.1 e
3.2). RF11 a RF16 são requisitos novos, acrescentados nas Entregas 3 e 4. Os nomes de teste são
métodos das classes em `src/test/java`; o resultado da última execução está em
[`testes/resultado-testes.txt`](testes/resultado-testes.txt).
